Triage Reference Guide

Severity Classifications:

  • CRITICAL (80+): Immediate resuscitation
  • SERIOUS (50-79): High priority; urgent
  • MODERATE (20-49): Moderate priority
  • STABLE (<20): Non-urgent care

Clinical Rule Triggers:

  • Oxygen < 90% (+50)
  • Heart Rate > 120 bpm (+30)
  • Stroke / Unconscious (+50)
  • Heavy Bleeding (+40)
  • Difficulty Breathing (+30)
